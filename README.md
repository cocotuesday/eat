# Weekly Dinner Plan

Open `index.html` in a browser. Use the arrows to choose a week, then select one recipe for each day from Monday through Sunday. The selected recipe's ingredients and directions appear in its day card.

After all seven dinners are selected, choose **Make shopping list** to combine ingredients and see an estimated Walmart total. Remove items you already have, search Walmart for extra items, then enter the price you find to add them to the list and total.

Use **Download image for Sparky** to save a PNG shopping list for upload to Walmart Sparky. **Download text list** saves a plain-text copy. The price snapshot is dated November 25, 2026, and uses ZIP code 83440 listings where available; prices can change, so confirm them with Walmart.

Weekly selections and shopping-list edits are saved in the browser on this computer. To add or rename recipes, edit the `recipes` list in `index.html`.
